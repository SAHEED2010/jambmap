# JAMB Center Locator 2025

A modern Next.js application to help students find their nearest JAMB registration centers in Nigeria.

## Features
- Search by center name or town
- Filter by state
- Interactive map integration
- Native sharing support
- Integrated directions via Google Maps

## Tech Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Geolocation API

## Getting Started
1. Install dependencies: \
pm install\
2. Run development server: \
pm run dev\
